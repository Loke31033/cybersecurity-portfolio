## Publish with GitHub Pages
1. Open your repository: https://github.com/Loke31033/-Loke31033.github.io
2. Upload `index.html` and `resume.pdf` to the repository root, replacing the old `index.html` only after reviewing the new version.
3. Commit to the `main` branch.
4. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
5. Open the Pages URL shown by GitHub. For the repository named `-Loke31033.github.io`, it is expected to be:
   https://loke31033.github.io/-Loke31033.github.io/
